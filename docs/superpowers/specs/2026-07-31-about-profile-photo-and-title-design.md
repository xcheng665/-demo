# About 页面照片与标题更新设计

## 目标

更新 About 页面左侧个人简介照片，并将右侧主标题开头由“建筑设计”改为“建筑技术”。

## 变更范围

- 使用用户提供的黑白人物照片作为新头像来源。
- 将照片处理为带透明通道的 PNG：保留人物与前景建筑模型，移除白色背景；不添加新元素、文字或水印。
- 以新 PNG 替换 `public/assets/profile-color.png`，从而保留现有 `AboutPage` 的图片引用、尺寸、圆角和红色描边样式。
- 将 About 页面主标题替换为“建筑技术，是我理解场地与人的方式。”，保留换行、其它简介内容和页面结构不变。

## 实现与验证

1. 生成并检查透明 PNG 的透明边角、人物边缘及模型细节。
2. 更新 `src/App.tsx` 的标题文本，并替换头像资源。
3. 构建项目，确认 TypeScript/Vite 构建通过；在浏览器预览 About 页面，确认照片未变形、背景透明且标题正确。
4. 仅提交本次照片、标题和设计说明，并推送到 `master`。

## 边界与错误处理

- 如果抠图出现明显白边或损失人物头发/模型细节，先调整边缘处理再使用，不以有瑕疵的资源覆盖原头像。
- 不修改联系方式、履历、其余页面标题或既有布局样式。
