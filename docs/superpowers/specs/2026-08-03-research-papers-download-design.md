# Research Papers Download Design

## Goal

在作品集的“数据科研”模块展示三篇相关论文，并提供全文 PDF 下载；在“数学建模”模块单独展示《电工杯 B 题》全文下载。

## Scope

### 数据科研

1. 椰壳混凝土建筑围护结构 SCI 论文
2. 台风后恢复管理多智能体 / Last Planner System 论文
3. 海口遗产知识图谱论文

第一篇只提供 SCI 论文正式稿，不展示“椰壳混凝土性能研究报告”。

### 数学建模

1. 内容主题：电工杯 B 题

卡片标题使用论文的内容主题，不使用“数学建模”作为标题；标题下方标注“电工杯一等奖”。

该论文属于数学建模成果，不放入数据科研列表。

## Information architecture

- 在 `src/portfolioData.ts` 中定义可复用的论文数据类型和论文列表。
- 数据字段包括：编号、中文标题、英文标题（如有）、研究方向、摘要、文件类型和下载路径。
- “数据科研”和“数学建模”模块分别传入自己的论文数组。
- PDF 文件放入 `public/papers/`，文件名使用安全的英文或拼音命名，页面展示使用中文标题。

## UI design

- 使用纵向堆叠的编辑档案卡，每张卡包含编号、研究类型、标题、摘要和“下载全文 PDF”按钮。
- 延续当前作品集的纸张色、细边框、衬线字体和绿色强调色。
- 长标题自然换行，不截断；摘要保持短段落，使卡片高度稳定。
- 下载按钮支持鼠标点击和键盘聚焦，并使用明确的下载文案。
- 移动端采用单列卡片，下载按钮扩展为整行宽度以保证触控区域。
- 数学建模模块沿用同一张卡片组件，但卡片标题显示内容主题“电工杯 B 题”，并在标题下方显示“电工杯一等奖”。

## File handling

- 第一篇复制用户提供的 SCI 正式稿。
- 第二、三、四篇复制用户指定的正式稿。
- 页面使用 `/papers/<safe-file-name>.pdf` 站内路径，避免直接依赖外部本地路径或中文 URL 编码。
- 如果论文数据没有有效文件路径，卡片仍可展示信息，但不渲染失效下载入口。

## Validation

- TypeScript 类型检查。
- Vite 生产构建。
- 检查四个 PDF 是否存在于 `public/papers/`。
- 检查数据科研页面显示三张卡片，数学建模页面显示一张卡片。
- 检查桌面端和移动端卡片布局及下载按钮可用性。

## Out of scope

- 不新增在线 PDF 阅读器。
- 不将“椰壳混凝土性能研究报告”作为独立论文卡片。
- 不修改其他实践卡片、路由或 AI 功能。
