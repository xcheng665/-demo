# 项目详情页横向滚动设计

## 目标

将项目详情页从项目封面开始的连续内容屏改为桌面端左右滚动布局，同时保留手机端现有的上下纵向浏览体验。

## 交互范围

- 桌面端（视口宽度大于移动端断点）：详情页各个 `project-slide` 横向排列，每屏占满视口，使用横向滚动吸附。
- 桌面端鼠标滚轮的垂直滚动量转换为容器的水平滚动；触控板横向手势、Shift+滚轮和拖拽滚动保持可用。
- 桌面端支持键盘左右方向键移动到相邻详情屏，焦点顺序与内容顺序一致。
- 手机端：详情屏恢复纵向排列，使用纵向滚动吸附；现有触摸滑动和项目切换逻辑继续有效，不拦截手机页面的垂直滚动。
- 项目上一页/下一页控件继续固定在每个详情屏左右两侧，不与详情屏内部滚动控件合并。

## 实现边界

- 仅修改 `ProjectDetailPage` 的详情滚动容器、必要的滚轮事件处理，以及项目详情相关 CSS。
- 不修改项目列表、首页、About 页面或项目数据结构。
- 不改变详情屏的内容、动画、图片/视频资源和项目间导航 URL。

## 技术方案

- 桌面端容器使用 `display: flex`、`overflow-x: auto`、`overflow-y: hidden` 和 `scroll-snap-type: x mandatory`；详情屏使用 `flex: 0 0 100%` 与 `scroll-snap-align: start`。
- 滚轮转换仅在桌面端且容器仍可水平移动时生效；到达两端时不阻断页面默认行为，避免产生无法退出的滚动陷阱。
- 移动端媒体查询覆盖为纵向 `display: block`、`overflow-y: auto`、`scroll-snap-type: y mandatory`，并禁用桌面端滚轮转换。
- 保留现有触摸方向判断；桌面端不依赖触摸事件切换项目，移动端仍可左右滑动切换项目。

## 验证

1. 运行生产构建，确认 TypeScript 和 Vite 构建通过。
2. 桌面端验证：滚轮、触控板/Shift+滚轮、键盘左右键和吸附定位；检查详情屏不会出现垂直滚动条。
3. 手机尺寸验证：页面可正常上下滑动，详情屏顺序和项目切换不回归。
4. 检查 Git 差异仅包含详情页组件、详情页样式和本设计说明。
