# 项目首页文字说明设计

## 目标

在五个项目首页右侧统一展示“问题、策略、成果”三条横向信息栏，让访问者快速理解项目逻辑，同时保持下方三张作品图在首屏内完整可见。

## 版式

- 三条信息栏从上到下排列，分别为“问题”“策略”“成果”。
- 每条栏内部横向排列编号、标题和正文。
- “问题、策略、成果”使用较大的绿色标题，与编号及正文形成清晰层级。
- 三条栏共享现有米白、深灰、低饱和绿色和细边线的编辑式视觉语言。
- 删除独立的 `Project Summary` 页面，不再增加额外详情页。

## 文案密度

- 五个项目分别提供与自身主题对应的专属文案。
- 每项正文控制在约 28–40 个汉字。
- 以当前桌面栏宽为基准，每项稳定显示约 2–3 行。
- 文案表达顺序统一：问题说明矛盾，策略说明空间或技术动作，成果说明最终价值。
- 不使用空泛口号，不改动已有项目标题。

## 响应式与首屏约束

- 桌面端保持三条横向栏，并让说明区高度与左侧项目信息区协调。
- 移动端仍按“问题、策略、成果”顺序纵向阅读，每条内部保持编号、标题和正文的清晰层级。
- 文案增加后不扩大下方媒体卡高度；图片说明和作品图仍需完整进入首屏。

## 验证

- 检查项目 01–05 均显示三条横向信息栏及独立文案。
- 检查正文为 2–3 行且无溢出、遮挡或异常空白。
- 检查下方三张图片在常用桌面高度下完整显示。
- 运行生产构建，确认 TypeScript 与打包通过。
- 网页审核通过前不提交 GitHub。
