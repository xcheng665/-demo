# 首页项目详情滚动预览页设计

## 目标

在首页首屏下方新增一整页项目预览，让访客在进入项目之前即可看到项目详情页的连续阅读体验。

## 信息与跳转

- 预览媒体使用用户提供的滚动录屏。
- 预览内容对应项目 01「山海 · 绿境」。
- 主按钮直接跳转至 `/projects/01`。

## 桌面端版式

- 首页保持两段纵向结构：既有首页首屏 + 新增项目详情预览页。
- 新增页左侧为编号、中文标题、英文标题、说明与进入项目的按钮。
- 右侧为带细边框与阴影的视频容器，视频自动静音循环播放，呈现项目详情的连续切换效果。
- 页面底部增加轻量滚动提示，使第二页的存在与浏览方向清晰可见。

## 交互与适配

- 首页保留自然的纵向浏览；在支持的桌面视口中以整屏滚动节奏呈现。
- 视频允许用户暂停与恢复播放，并默认使用 `playsInline`、静音和循环，避免自动播放被浏览器阻止。
- 窄屏设备上说明区与视频上下排列，视频宽度适应容器，不裁切关键画面。

## 视觉语言

- 延续首页的暖白纸张底色、橄榄绿强调色、细边框和柔和阴影。
- 视频作为视觉中心，不添加额外装饰边条，确保页面干净且聚焦于项目阅读体验。
