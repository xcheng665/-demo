# 首页项目详情滚动预览页设计

## 目标

在首页首屏下方新增一整页项目预览，让访客在进入项目之前即可看到项目详情页的连续阅读体验。

## 信息与跳转

- 预览媒体使用 `public/assets/project-pages` 中的全部项目详情图。
- 每张图片保留其所属项目的跳转关系。

## 桌面端版式

- 首页保持两段纵向结构：既有首页首屏 + 新增项目详情预览页。
- 新增页仅保留全宽的图片滚动组件，不显示左侧说明文字。
- 三列图片轨道持续自动滚动，使用首尾重复的图片保证循环自然。
- 任意图片均可点击，并直接进入其所属项目的详情页。

## 交互与适配

- 首页保留自然的纵向浏览；在支持的桌面视口中以整屏滚动节奏呈现。
- 鼠标悬停或键盘聚焦时暂停滚动，便于选择任意图片。
- 窄屏设备改为双列滚动，保持纵向阅读且每张图片均可点击。

## 视觉语言

- 延续首页的暖白纸张底色、橄榄绿强调色、细边框和柔和阴影。
- 图片滚动组件作为视觉中心，不添加说明文字，确保页面干净且聚焦于项目阅读体验。
