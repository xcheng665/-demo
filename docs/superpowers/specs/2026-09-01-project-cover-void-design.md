# 项目封面留白区装饰设计

## 目标

为项目 01–05 的标题与项目信息之间留白区增加轻量的建筑制图式视觉元素，减少空旷感，同时保持正文可读性与现有版式结构。

## 方案

使用统一的细线网格、短比例刻度和项目编号标记。装饰通过项目封面左侧容器的伪元素渲染，不增加新的内容节点，不改变标题、项目信息或图片的布局尺寸。

## 视觉约束

- 线条使用现有 `--line` / `--faint` 色系，低对比度呈现。
- 项目编号使用当前项目编号动态显示，保持 01–05 与页面内容一致。
- 装饰仅在桌面端留白区显示；窄屏继续保持简洁的移动布局。
- 不遮挡标题、项目信息或交互控件。

## 验证

运行 `npm run build`，确认 TypeScript 与 Vite 构建通过，并检查改动仅影响项目封面留白区。
