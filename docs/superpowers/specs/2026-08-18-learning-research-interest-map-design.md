# 程志远学习与研究兴趣图谱设计规范

日期：2026-08-18  
方案：B｜双核心桥接图

## 1. 设计目标

制作一张横版、中文、可用于作品集与导师沟通的学习与研究兴趣图谱。图谱以程志远的真实本科经历为左侧核心，以面向韩梦涛老师及华中科技大学低空技术与工程交叉方向的研究兴趣为右侧核心，通过已有能力和可继续学习的方法形成中部桥梁。

参考图片仅用于借鉴白底、细线连接、圆形节点、低饱和分组色和大量留白的视觉语言，不复用参考图中的人物、项目、竞赛或研究内容。

## 2. 画布与视觉语言

- 画布：A3 横版，比例约 1.414:1，兼顾打印、作品集插页和屏幕阅读。
- 背景：暖白色，避免纯白造成刺眼。
- 连接线：浅灰细线；个人已有经历与导师公开研究使用实线，个人拟拓展兴趣使用虚线。
- 节点：圆形为主，核心节点最大，桥梁节点次大，证据与细分主题为小圆点或小方块。
- 配色：个人经历使用墨绿与沙金；方法桥梁使用蓝灰；韩老师研究使用深蓝紫；低空拓展兴趣使用砖红；正文使用深灰。
- 标题：左上角“LEARNING & RESEARCH MAP”，下方小字“程志远｜建筑环境 × 数字技术 × 低空工程兴趣图谱”。
- 风格：学术、克制、轻量，不使用渐变、3D、装饰插画或照片。

## 3. 信息结构

### 3.1 左核心：个人经历与能力

中心节点：

- 程志远
- 海南大学建筑学｜2026 届

一级分支及主要节点：

1. 建筑与环境基础
   - 建筑设计 1—6 均分 90+
   - 建筑物理：热工、声光环境、实验
   - 绿色建筑与性能分析
   - 场地研究、空间叙事、地域气候响应
2. 绿色低碳研究
   - 椰壳废弃物建筑围护结构与能耗研究
   - 海岛热湿气候、传热传湿与能耗
   - 垂直绿化光伏一体化外墙专利成果
   - 绿色建筑技能与创意大赛一等奖
3. 数字建模与分析
   - Revit / BIM / SketchUp
   - Rhino / Grasshopper 参数化
   - Python / NumPy / Pandas
   - 数学建模、数据整理与指标计算
4. 科研与协同
   - 建筑遗产本体知识图谱：第一作者英文会议论文稿
   - 多源图纸、构件、材料与证据治理
   - 台风后恢复多智能体协同：第二作者 EI 会议论文
   - 知识图谱、约束识别与 Agent 工作流

### 3.2 中部桥梁：可迁移的方法能力

桥梁节点从左核心连接右核心：

- 多尺度环境数据组织
- 建筑与城市形态参数化
- BIM / 知识图谱 / 数字孪生
- CFD 与 LBM-LES（研究生阶段重点学习）
- 机器学习辅助污染源定位
- 多智能体任务规划与约束管理

其中“CFD 与 LBM-LES”“机器学习辅助污染源定位”必须明确标注为拟学习或拟深化能力，不写成已完成经历。

### 3.3 右核心：未来研究兴趣

右核心标题：

- 建成环境与城市低空安全
- 韩梦涛老师方向 × 低空技术工程

右核心分为两组，并用图例严格区分。

#### A. 韩梦涛老师公开研究方向（实线）

- 城市与建筑风环境
- 城市微气候与绿色建筑节能
- CFD / LBM-LES 数值模拟
- 室内污染源定位
- 气溶胶、飞沫与污染物扩散
- 建筑空间、通风模式与健康风险

#### B. 程志远拟拓展的低空研究兴趣（虚线）

- 城市低空微气象与三维风场
- 高密度建成环境中的风扰动安全
- 无人机环境感知与多源数据融合
- 城市低空三维风险地图
- 安全航路规划与动态任务调度
- 建筑外墙、基础设施与灾后巡检
- 数字孪生城市与多智能体协同

### 3.4 核心研究问题

在右核心下方设置一条醒目的总结问题：

“城市建筑形态如何通过风场、热环境与污染物传播，进一步影响低空飞行安全、环境感知和应急巡检？”

该问题是基于个人经历、韩老师公开研究与华中科技大学低空技术与工程方向形成的申请者推演，不代表韩老师已经主持该具体课题。

## 4. 信息边界与证据规则

- 个人经历仅采用作品集、知识库及自荐信中已确认的信息。
- 韩老师研究采用华中科技大学教师主页与公开论文资料核对。
- 低空技术与工程采用华中科技大学公开学科建设信息核对。
- 公开事实使用实线；个人兴趣推演使用虚线，并在图例中写明“拟拓展”。
- 不将“低空技术工程”直接归属于韩老师，不编造导师课题、招生承诺或合作关系。
- 不把英文国际会议论文稿描述为已被 EI 收录；台风后恢复论文保留自荐信中已确认的第二作者与 EI 会议信息。

## 5. 交付形式

1. 高清 PNG：使用内置 imagegen 生成双核心桥接图视觉稿，并检查中文与节点层级。
2. 可编辑 PPTX：以独立文本框、圆形节点、线条和图例重建，确保主要文字、位置、大小和颜色可编辑。
3. Canva 使用：PPTX 可导入 Canva 继续编辑。当前 `canva-edit-design` 能编辑已有 Canva 设计，但不能从零添加新文本框；用户未提供现有 Canva 设计链接，因此本轮不声称已在 Canva 内创建或保存设计。若用户导入 PPTX 后提供 Canva 设计链接，可再按事务预览、用户批准、提交的流程调整。

## 6. 质量检查

- 核对姓名、学校、项目、论文作者身份和获奖表述。
- 检查导师公开研究与个人拟拓展兴趣是否通过实线/虚线清楚区分。
- 检查所有中文标签无乱码、错字、重复或被连线遮挡。
- 检查 A3 横版在 100% 缩放和缩略图状态下均能读出两大核心与桥梁逻辑。
- PNG 与 PPTX 的信息结构保持一致；PPTX 中的文本和形状可单独选择与编辑。
