# 项目展示图片纸张叠层设计

## 目标

为项目详情页进入后的图纸展示页增加克制的实体印刷纸张观感。视觉参考为置于浅灰台面上的建筑作品集：正面作品纸、略微外露的底纸、清晰纸边高光和柔和落影共同构成有厚度的画册纸页。效果不模拟破损、折痕或复古旧纸。

## 视觉方案

- 图片保持现有比例、清晰度与说明文字；不修改任何原始资源。
- 每张后续图纸增加一张位于下方、比正图略大的纸张衬底：暖灰白底色、细纤维感与极轻颗粒。
- 衬底相对于正图向右下错位，在桌面端露出约 7–12px 的右侧与下侧纸边；移动端缩小露出范围。
- 正图纸边保留细微亮边；正图、底纸与页面背景之间分别使用不同强度的短距离柔影，建立参考图中的双层纸页厚度，不能遮挡图像边缘或说明文字。
- 纹理与颗粒仅作用于纸张衬底；正图、正文、页面背景和视频内容保持干净。
- 效果强度遵循 80% 干净排版、15% 纸张质感、5% 印刷瑕疵的比例；小字号图纸、线稿与灰度分析图优先保证可读性。纸张层不作旋转或夸张位移，保持建筑作品集的精确感。

## 实现边界

- 仅改动项目详情页进入后的图纸媒体容器及相关 CSS；项目首屏概览卡不启用该效果。
- 使用 CSS 伪元素和渐变生成纸色、纤维和颗粒观感，不新增下载资源，也不向每张原图写入滤镜。
- 视频、项目首页封面、导航、项目标题、图片数据和横向浏览交互保持不变。
- 在不支持混合效果的浏览器中，衬底退化为浅色纸张与普通阴影，内容仍完整可读。

## 响应式与无障碍

- 桌面端维持轻微纸张错位；移动端减少偏移量与阴影，避免压缩有效图像空间。
- 装饰层不可接收指针事件，且不进入辅助技术读取顺序。
- 若用户启用减少动态效果，纸张层保持静态，不引入动画。

## 验证

1. 检查五个项目详情页的每张静态作品图片都有统一、轻量的叠纸效果。
2. 检查图片说明、图像边缘、横向滚动和项目切换不受影响。
3. 在常用桌面与手机尺寸检查错位边缘、阴影、裁切与可读性。
4. 运行 `npm run build`，确认 TypeScript 与生产构建通过。
