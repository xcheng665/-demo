# 跨学科实践横向浮动 OGL 画廊设计

## 目标

将“跨学科实践与项目表达”页面红框区域中现有的静态扇形卡组替换为横向连续画廊。画廊以用户提供的 `CircularGallery` 为基础，卡片沿同一水平基线连续滑动，使用 `bend={0}`，不再形成弧线或倾斜瀑布。

视觉上保留现有五张实践卡片、中文标题、英文标题、序号、页面配色和下方详情区域；仅改变卡片展示与切换方式。画廊在静止时有幅度很小、错相的上下浮动；拖拽或滚轮滑动时保留 OGL 的细微图像波动。动画必须在“减少动态效果”系统设置下停止。

## 组件边界

### `CircularGallery`

新增独立 React 组件及样式，封装 OGL renderer、相机、媒体平面、拖拽、滚轮和键盘输入。项目已安装 `ogl`，不增加依赖。

组件接收：

- `items`：由现有 `practices` 数据派生，包含卡片图片、序号、中文标题和英文标题。
- `activeIndex`：外部当前主题索引，使下方详情区和画廊能够双向同步。
- `onActiveIndexChange`：每次横向滑动吸附到一张卡片时回传当前项目。
- `bend={0}`、`scrollEase={0.02}`、`borderRadius={0.05}`：固定为已确认的展示参数。
- `floatAmplitude`：仅用于静止状态下的轻微上下漂浮；在减少动态效果设置下为 0。

画廊本身负责 WebGL 资源的创建与销毁、监听器清理、窗口大小变化和图片加载失败时的安全退化。组件销毁时取消动画帧、解绑事件、删除 canvas。

### `OtherPage`

保留 `activePractice` 作为唯一的主题状态来源。将当前 `practice-deck` 的映射卡片替换为 `CircularGallery` 容器；下方详情、上一张/下一张按钮与指示点不改变。

- 使用详情区按钮切换时，画廊平滑移动到相应卡片。
- 使用画廊拖拽、滚轮或左右方向键切换时，更新 `activePractice`，使详情同步更新。
- 现有小屏横向可滚动卡组改为同一画廊的紧凑配置；若 WebGL 不可用，回退为原有的横向卡片列表，保证内容可访问。

## 动效与可访问性

- 画廊为可聚焦区域，提供左右方向键导航，并保留拖拽和滚轮操作。
- 轮播位置会在输入停止后吸附至完整卡片，不产生半张卡片的停留状态。
- 当前卡片的中文标题与序号被暴露给辅助技术；画布有明确的区域标签与操作说明。
- `prefers-reduced-motion: reduce` 下，不执行持续浮动、材质波动或自动滑动；卡片依然可通过按钮、滚轮和键盘切换。
- 不使用远程字体链接，沿用项目本地字体体系，避免字体加载失败或与中文标题风格冲突。

## 验证

1. 运行 `npm run build`，确保 TypeScript 与 Vite 生产构建通过。
2. 在桌面端检查五张卡片水平排列、中央项目焦点、拖拽/滚轮/键盘吸附和详情联动。
3. 在 390px 宽度下检查画廊不会截断页面、卡片可切换且详情可读。
4. 在减少动态效果下检查卡片保持静止但所有切换路径仍可用。
5. 检查 OGL/canvas 加载失败时，原始卡片内容仍可浏览和切换。

## 范围边界

仅修改“跨学科实践与项目表达”页的实践卡片画廊及其必要组件/样式；不修改项目标题、卡片图片、实践详情内容、其他页面的轮播，亦不包含全局鼠标光晕删除的独立改动。
