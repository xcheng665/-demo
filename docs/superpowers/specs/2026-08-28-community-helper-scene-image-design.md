# 社区互助场景图优化设计

## 目标

将社区互助案例中共用的场景图片替换为一张更清晰、自然的横向社区生活照片，提升五个手机页面的整体完成度。

## 视觉方向

- 方向：温暖自然。
- 色彩：米白、鼠尾草绿、清晨金色日光。
- 场景：现代住宅社区的步道、快递柜、绿植与少量自然互动的居民。
- 构图：横向宽幅，人物和主要物体留在画面中部，兼容地图裁切、卡片裁切和封面裁切。
- 约束：不生成文字、标识、水印、手机界面或拼贴版式。

## 变更范围

- 新增一张项目内图片资源，不覆盖现有资源。
- 仅更新 `src/App.tsx` 中社区互助案例的 `communitySceneUrl` 引用。
- 保持五个手机页面、中文文案、功能结构、标题和样式不变。

## 验证

- 检查新图在地图、快递代取、物品互借、顺路出行和个人页中的裁切效果。
- 运行项目构建，确保资源路径有效。
